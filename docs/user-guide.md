# mystocktracer 使用說明

本文面向下載安裝 mystocktracer 桌面版的一般使用者。

台股行情、指數、三大法人、融資融券、基本面與公司事件資料來自 TWSE、TPEx 與 MOPS 等官方來源，**不需要任何額外設定**即可使用。只有「產生 AI 研究摘要」與 AI 對話需要你自行設定大模型 API。

> mystocktracer 不提供大模型額度。大模型費用由服務商依實際 API 用量收取。
>
> 本產品僅用於學習、研究與資訊整理，不構成投資建議、收益承諾或交易依據。

## 下載與首次啟動

1. 開啟 [mystocktracer GitHub Releases](https://github.com/nanachi1212/mystocktracer/releases/latest)。
2. 下載適合你電腦的安裝檔：
   - Apple 晶片 Mac（M1、M2、M3、M4 等）：選擇檔名含 `macos-arm64` 的 DMG。
   - Intel 晶片 Mac：選擇檔名含 `macos-x64` 的 DMG。
   - 64 位元 Windows：選擇檔名含 `windows-x64-setup` 的安裝程式。
3. macOS 開啟 DMG 後將應用拖入「應用程式」；Windows 開啟安裝程式並依提示完成安裝。
4. 啟動應用程式。一般使用者不需要另外安裝 Node.js、Go 或 Python。

應用程式會自動從本 repository 的 GitHub Releases 檢查更新；下載與重新啟動一律需要你手動確認。

> 若你使用的是 Phase B1 以前、仍從舊 Alibaba OSS 來源檢查更新的版本，請先從上述 GitHub Releases **手動安裝一次**。安裝後才會改用本 repository 的自動更新通道。舊版本無法從新版 client 反向取得更新來源設定。
>
> 手動升級會沿用原本的應用資料目錄，但直接執行 NSIS 或 DMG 安裝檔不會觸發應用程式內建的更新備份。升級前請先關閉應用程式，手動將目前的應用資料目錄複製到安全的外部位置；完成後請確認自選股、持倉、研究歷史與事件提醒都可見，並在確認前保留該備份。

## 不需設定就能使用的功能

- **今日總覽**：市場、持股、自選股、事件提醒、研究更新與需要注意。
- **台股選股器**：以官方市場快照篩選與排序。
- **自選股**與**持倉**：儲存在本機資料庫。
- **事件提醒**：公司事件收件匣與已讀狀態。
- **個股分析**：官方證據與確定性解讀。
- **市場廣度／市場情緒／產業雷達**。

畫面會明確顯示資料日期與狀態。無法取得的資料會標示為不可用，**不會顯示為 0**。

## 設定大模型前先了解這些

AI 研究摘要與 AI 對話需要呼叫你自行選擇的大模型 API。有兩個容易混淆的概念：

- **網頁版／App 會員**：只讓你在該服務商自己的網站或 App 使用，**不能**用於第三方應用。
- **開放平台 API 額度**：才是 mystocktracer 這類第三方應用呼叫模型時使用的。

所以即使你已經是某服務商的付費會員，仍需要另外到其**開放平台**建立 API Key 並儲值。

## 設定模型連線

1. 到你選用服務商的開放平台註冊帳號並儲值 API 額度。
2. 在開放平台建立一組 API Key，名稱可填 `mystocktracer` 之類容易辨識的字。API Key 通常只會完整顯示一次，請立即複製保存。
3. 開啟 mystocktracer，點擊左側欄底部的「系統設定」。
4. 在「Hermes 模型執行環境」區塊：
   - 選擇「雲端 API」供應商，或點選「本地模型」預設值（LM Studio、Ollama 等 OpenAI-compatible 介面）。
   - 確認 **API Base URL**。
   - 貼上 **模型 API Key**。使用本機模型時通常可留空。
   - 點擊「取得模型清單」後從下拉選單挑選模型，或直接手動輸入模型名稱。
5. 點擊「儲存並測試連線」。成功時會顯示實際回應與延遲。

「模型回應等待時間」預設 300 秒，可依模型速度調整（30–3600 秒）。

## 切換或新增模型設定

「模型設定」下拉選單可以保存多套設定。每套設定各自保存自己的 API Key，切換設定不會覆蓋其他金鑰。點「新增設定」建立、點「刪除」移除（至少保留一套）。

## 常見問題

### 點擊「儲存並測試連線」後提示 401 或 403

多半是 API Key 錯誤、已被刪除，或與所選 Base URL 不屬於同一個服務商。請重新複製完整的 Key，並確認 Base URL 與供應商一致。

### 提示 404、模型不存在或無法呼叫

模型名稱與該服務商的實際模型 ID 不一致。請先點「取得模型清單」，從清單中挑選。

### 「取得模型清單」失敗，但我已經填寫了 Key

先確認 Base URL 可從本機連線（企業網路或 VPN 可能阻擋），再確認該服務商的模型清單介面與所填 Base URL 屬於同一版本路徑。使用本機模型時，請確認本機推論服務已啟動。

### AI 研究長時間沒有完成

模型可能正在長時間推論或服務端排隊。可提高「模型回應等待時間」，或改用回應較快的模型。

### 已儲值會員，為什麼仍提示餘額不足

會員方案與開放平台 API 額度是分開計費的。請到該服務商的**開放平台**確認 API 餘額。

### 台股資料暫時為空

先看畫面顯示的來源、交易日與新鮮度狀態。TWSE、TPEx 與 MOPS 的公開介面可能臨時限流或調整欄位。若需回報，請到「系統設定 → 執行日誌」開啟日誌目錄，將問題發生時間附近的日誌提供給開發者；日誌會先隱藏金鑰與憑證，但送出前仍建議自行檢查。

## 金鑰與資料安全

- API Key 只應貼到 mystocktracer 的「模型 API Key」輸入框，不要傳送給任何人。
- 不要將完整 API Key、帳號密碼或持倉截圖提交到公開 Issue 或群組。
- 模型金鑰交給本機 Hermes 保存，設定頁不會重新讀取金鑰明文。
- 自選股、持倉、研究歷史與事件提醒都保存在本機資料庫，不會上傳。
- 在公用電腦使用後，請清除已儲存的模型金鑰。
- 若懷疑 API Key 外洩，請立即到服務商開放平台刪除舊 Key 並建立新的。
- 使用第三方模型時，請遵守該平台的服務條款與使用限制。
