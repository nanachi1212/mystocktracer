# mystocktracer 使用說明

## 安裝與升級

從 [mystocktracer Releases](https://github.com/nanachi1212/mystocktracer/releases) 下載符合 Windows 或 macOS 架構的安裝檔，完成安裝後直接啟動。一般使用不需額外安裝 Node.js、Go 或 Python。程式會檢查本 repository 的更新；下載及重新啟動由使用者確認。

如果目前使用的是仍從舊來源更新的版本，需先手動安裝一次新版本。手動安裝不會執行程式內的更新備份；升級前請關閉程式，將原有應用資料目錄複製到外部安全位置。啟動新版後確認自選股、持倉、研究歷史與提醒都可見，再決定何時移除備份。既有目錄的選擇與複製驗證見 [資料遷移說明](desktop-identity-migration.md)。

## 不需模型設定的功能

每日總覽、自選股、持倉、事件提醒、個股官方證據、選股器、廣度、情緒與產業雷達可直接使用。畫面會標示資料來源與日期。資料暫時不可用時會呈現狀態或缺值，不會把未知數字填成零。

## 連接 AI 模型

一般 AI 對話與「產生 AI 研究摘要」需要使用者自行提供模型服務。服務商網站或 App 的會員方案通常與開放平台 API 額度分開；請依服務商的 API 規則取得金鑰。在「系統設定 → AI 模型」選擇 provider，確認 Base URL、模型及 API mode，必要時填入 API Key，然後儲存並測試連線。Ollama 與 LM Studio 的本機預設值經 `custom`／OpenAI 相容介面連接，通常可留空金鑰。

可以建立多套模型設定，各 profile 的密鑰分別保存。切換模型不會覆寫其他 profile 的金鑰；若要刪除，請使用明確的清除操作。模型回應逾時預設為 300 秒，可設為 30–3600 秒。模型設定頁只顯示密鑰是否已設定，不會讀回明文。

## 排查

- 401／403：檢查金鑰是否屬於選定服務商、是否仍有效及是否有 API 額度。
- 404 或模型名稱無效：使用「取得模型清單」核對實際 ID 與 Base URL 路徑。
- 本機模型無法連線：確認 Ollama／LM Studio 的服務已啟動，且使用相同 loopback port。
- 台股資料空白：先核對畫面上的來源、交易日與新鮮度，再查看「系統設定 → 執行日誌」。回報前請遮罩憑證、帳戶及持倉資料。

本機自選股、持倉、提醒與研究歷史不應上傳到公開 Issue。AI 模型輸出可能有延遲、遺漏或錯誤，請以原始官方資料獨立核對；本產品不提供買賣建議。
